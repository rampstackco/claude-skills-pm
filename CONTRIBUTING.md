# Contributing to claude-skills-pm

claude-skills-pm is a curated PM-focused subset of the [claude-skills](https://github.com/rampstackco/claude-skills) catalog. Contributions are limited in scope by design.

## Where to contribute

### Skill content changes
All skill content changes should be made to the source repository at [claude-skills](https://github.com/rampstackco/claude-skills). Once accepted there, the change can be re-synced to this PM subset.

### Adding or removing a skill from the PM subset
Open a discussion at [claude-skills discussions](https://github.com/rampstackco/claude-skills/discussions) proposing the change. The discussion should include:

- The skill name and what it does
- Why it belongs (or doesn't belong) in a PM-focused subset
- Which skill, if any, you'd remove to keep the set focused
- Whether the skill is universally applicable across PM contexts (the bar for inclusion here)

### Bug reports for the PM repo
If you spot a problem with how the PM repository has copied or referenced a skill (missing files, broken cross-references, README inaccuracies), open an issue here.

## What's out of scope

- New PM skills not in claude-skills
- Skills tied to specific tools, vendors, or methodologies that aren't broadly applicable
- Non-PM skills beyond the curated set
- Major reorganization of the skill structure
- Plugin packaging for specific Claude Code harnesses
